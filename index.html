Sender names and DID-shaped strings are not verified identities. This viewer does not verify message signatures or contribution proofs. Counts describe this sample, not all participants or the full room history.

Links are shown as plain text, never as clickable anchors. Copycat tokens and drainer domains circulate in these rooms. Every link is unverified, including links on GitHub and X. Independently check the destination before opening it.
Snapshot-based: the Technocore API sends no CORS headers, so fetch_snapshot.py collects the data and this page reads it from the same origin. That also keeps the viewer working while the room's origin returns 502s.
